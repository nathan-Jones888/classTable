# 松课微信小程序

这是与现有 Vite/Capacitor 应用并列的原生微信小程序目录，可直接用微信开发者工具打开 `miniprogram/`。

## 当前能力

- 按第一教学周周一自动计算第几周和日期。
- 周视图展示课程、节次、教室、教师，支持前后周切换。
- 配置页支持粘贴教务系统课表页面文本，解析常见的“课程名 / 周次 / 星期 / 节次 / 教室 / 教师”内容。
- 配置页支持选择教务系统导出的 HTML、CSV、TXT、XLSX、XLS 文件，按星期列和节次行自动生成课程。
- 当前版本完全使用前端，不需要 CloudBase 或服务器。课程数据只保存在学生本机。
- 课程和第一周日期保存在本机缓存，密码不会保存。

## 开发者工具

1. 用微信开发者工具打开 `miniprogram/`。
2. 在开发者工具中执行“构建 npm”，让 `xlsx` 依赖生成 `miniprogram_npm`。
3. 学生在教务系统点击“导出”后，把导出文件发送到微信聊天，再在小程序配置页点击“选择 HTML / CSV / Excel 文件”。所有文件都在本地解析。
4. 学生也可以复制页面文字或 HTML，粘贴到配置页解析。
5. 学生密码不经过本小程序后端，课程数据只保存在本机缓存。

## 超星课表入口

当前提供的 `https://etbum.v.chaoxing.com/manage?ws=2` 会重定向到超星机构登录页，课程内容不在公开 HTML 中。手机号登录、机构账号登录和验证码需要在超星官方页面完成，不能用普通表单 POST 代替。正式支持该入口需要增加超星专用登录态方案，或让学生在超星页面完成登录后导出/复制课表内容再交给小程序解析。
